# Mineglo

독립적으로 만든 브라우저용 싱글플레이 voxel 샌드박스입니다.

## 조작

- `WASD`: 이동, `Shift`: 달리기, `Space`: 점프
- 마우스: 시점, 왼쪽: 파괴, 오른쪽: 설치
- `1`~`6`: 핫바 블록 선택, `R`: 새 세계

저장된 블록 변경 사항과 월드 시드는 브라우저의 Local Storage에 자동 보관됩니다.

## 성능 설계

월드는 16×16 청크 단위로 만들며, 플레이어 주변 5×5 청크만 유지합니다. 각 청크에서는 보이는 면만 한 지오메트리로 병합하여 그리기 호출을 줄였습니다. 픽셀 비율도 1.25로 제한해 저사양 노트북에서 GPU 부하를 낮춥니다.
